# Lane Justice

A comic 3D browser game about riding the bike lane and clearing cars that block it. Pull out the in-game phone, snap the evidence, and trigger one of four cartoon resolutions: explosion, disappearance, ticket, or tow.

## Play locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Controls

- `WASD` or arrow keys — pedal and steer
- `E` — pull out or pocket the phone
- `Space` — take a photo
- Touch controls are available on phones and tablets

## Build

```bash
npm run build
npm test
```

The game uses Three.js and procedural low-poly geometry, so no external 3D models are required.
