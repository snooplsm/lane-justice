# Lane Justice

A grounded 3D browser game about urban cycling and documenting traffic violations. Ride through moving traffic and timed intersections, pull out the rider's phone, photograph cars blocking the bike lane, and earn a triple bonus for catching vehicles past the stop line in a crosswalk during red.

## Play locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Controls

- `WASD` or arrow keys — pedal and steer
- `E` — pull out or pocket the phone
- `Space` — take a photo
- Touch controls are available on phones and tablets

## Build

```bash
npm run build
npm test
```

The game uses Three.js and procedural low-poly geometry, so no external 3D models are required.
